# 体彩号码实验室

面向 GitHub Pages 的超级大乐透、排列3、排列5、福彩3D、体彩7星彩、福彩双色球、福彩快乐8公开数据看板。页面展示最新已核验开奖、下一期开奖时间、每个玩法唯一综合推荐清单及相对模型评分。首页顶部提供各玩法导航按钮；复制文本仅包含玩法名称和候选数字。

首页保持简洁看板不变，另提供七个详情页：

- `/dlt/`：大乐透综合推荐5注、上期复盘与最近100期分析；
- `/pl3/`：排列3按百位、十位、个位独立分析后推荐5注；
- `/pl5/`：排列5使用自身五位置独立模型推荐5注、上期复盘与最近100期分析；
- `/fc3d/`：福彩3D使用独立位置模型推荐5注。
- `/qxc/`：体彩7星彩使用七位置束搜索独立模型推荐5注；
- `/ssq/`：福彩双色球使用红蓝分区、红球共现独立模型推荐5注。
- `/kl8/`：福彩快乐8使用选N独立模型，各玩法每期5组互不重叠的号码。

排列3、排列5、福彩3D各自独立校准位置模型；体彩7星彩、福彩双色球、福彩快乐8以及超级大乐透各自使用独立模型。排列3、排列5和福彩3D均分别展示各位置分析，避免“数字出现但位置错误”被误当作直选命中。

排列3、排列5和福彩3D不再展示独立热门区、冷门区；生成器按固定配额合并为唯一清单，并在每期开奖更新时自动重新计算。

## 模型方法（v3.2）

- **滚动回测校准**：每个玩法在自身历史上做滑动窗口回测（数字玩法300折、集合玩法240折），逐位置/逐区域选择衰减周期与历史窗口；
- **one-standard-error 参数选择**：公平开奖下回测格点的差异主要是噪声，参数只在与最优格点统计等价（一个标准误内）的集合里选最稳定的（最大窗口、最慢衰减），避免追逐回测噪声；
- **诚实基线**：每个回测指标同时输出二项标准误和“公平开奖神谕基线”（数字位为3/10；大乐透排序位使用顺序统计量的精确top-k概率质量），命中率应与基线对照阅读——观测值与基线在1–2个标准误内一致即说明开奖是公平的，模型评分只是候选之间的相对排序；
- **联合覆盖保障**：单注命中概率在公平开奖下与选哪些候选无关，但5注清单的联合覆盖面可以免费最大化——排列3、排列5和福彩3D把每个位置回测出的3个候选数字全部铺进5注；七星彩保证每个位置至少覆盖3个不同数字（束搜索的位置常自然覆盖更多）；大乐透保证5个互异后区对、后区并集≥8、前区并集≥20；双色球保证蓝球分带互异、红球并集≥26且任意两注最多重叠1个；快乐8同一选N玩法的5组号码完全互不重叠。
- **组合容错增强**：20折历史滚动检查中，新的分散约束使大乐透前区联合命中从1.80提高到2.45，双色球红球联合命中从3.70提高到4.55；这只是扩大组合覆盖，不代表单注中奖概率提高。

> 以上仅为公开信息整理后的娱乐分析，不构成任何购彩建议，请理性参考。模型相对评分不是真实中奖概率。

## 本地生成

```powershell
python -m pip install -r requirements.txt
python src/fetch_draws.py --history-limit 2000
python src/generate_dashboard.py
python -m http.server 8000 -d docs
```

访问 `http://localhost:8000`。官方接口若临时返回 403 或超时，抓取脚本会保留上一次已核验数据，并把状态写入页面数据。

## 自动发布

每日北京时间21:45开始，GitHub Actions每15分钟重试一次，最多执行到22:30；脚本按北京时间星期只抓取当天安排开奖的彩种。开奖结果先由官方接口抓取，再尝试用官方开奖页交叉核验；无法交叉核验时页面标记“待确认”，兑奖核对器不会给出中奖结论。

首页新增“兑奖核对”页面：可逐行粘贴基础单式票面文本，排列3和福彩3D支持直选、组选3、组选6，快乐8支持选N。记录仅保存到浏览器 `localStorage`，默认按单倍、基础投注、无追加估算奖金。


GitHub Actions 在每天北京时间22:10更新排列3、排列5和福彩3D；在每周日、周二、周五08:10更新大乐透，即在开奖前一天生成。亦可手动选择全部玩法、仅大乐透或每日数字玩法。仓库 Settings → Pages 的 Source 需选择 **GitHub Actions**。

## 数据源与日历

- 首选：中国体育彩票官方开奖接口与开奖信息页；
- 交叉核验：省级体彩网及公开历史页；
- 超级大乐透：周一、周三、周六 21:25 开奖（休市日除外）；
- 排列3、排列5：每日 21:25 开奖（休市日除外）。
- 福彩3D：每日 21:15 开奖（休市日除外），数据来自中国福利彩票官方接口；
- 体彩7星彩：每周二、五、日开奖；
- 福彩双色球：每周二、四、日开奖，数据来自中国福利彩票官方接口。
- 福彩快乐8：每日21:30开奖（休市日除外），每期从1–80开出20个号码；页面只输出选五玩法的5组候选。

法定休市属于例外事件，应以中国体育彩票当期公告为准。生成器按常规日历计算，并在页面明确标注“休市日除外”。

## v4.0 混合模型输出模板

排列三和福彩3D使用当前逐位滚动模型为主，融合 ZIP 模型的和值、跨度、奇偶、冷热回补和两码和差信号；所有 ZIP 信号只作低权重辅助，不使用硬杀号或硬过滤。页面统一按以下顺序展示：和值（2至3个）、跨度（2至3个）、奇偶结构、百位/十位/个位的热门与冷门及近100期出现次数，最后输出5个热门直选和5个冷门直选。每个位的前两个热门数字和前两个冷门数字重点标注；所有直选号码保留百位、十位、个位顺序。以上内容均为历史统计排序参考，不代表中奖概率。
